Selected work / Case study

Juapath

Helping schools, teachers and learners adopt an AI-enabled learning platform in practice.

Status
Ongoing
Sector
Education technology
My role
Onboarding, training, adoption, stakeholder engagement and commercial development
Image
Illustrative, not a product screenshot

Context

Juapath is an AI-enabled learning platform working with schools, teachers and learners. My work sits where the software meets the institutions that use it.

The problem

A learning platform only creates value when schools, teachers and learners actually use it.

Technology in education usually fails at adoption rather than at features. A school has to be set up, teachers need the confidence to use the platform in their lessons, and learners need support to keep using it after the first week.

My role

  • School onboarding: preparing each institution to adopt the platform.
  • Teacher training: practical sessions focused on using the platform in real lessons.
  • Learner adoption: support that helps learners start and keep using it.
  • Implementation support and stakeholder engagement with school leadership.
  • Commercial development with education institutions.

Approach

I treat adoption as an implementation problem. Each school is onboarded in a structured way, training is built around how teachers actually teach, and what schools and teachers report is fed back so the rollout improves over time.

The aim is the same as in any system I work on: people should understand the tool, trust it, and keep using it after launch day.

Status and evidence

Ongoing engagement. Verified results will be added here when they can be shared. No figures are claimed on this page.
